# Schermate per il README

`screenshots/` contiene le schermate usate da `README.md` (inglese) e `README.it.md` (italiano), già inserite in cornice: iPhone per il telefono, finestra di browser per il desktop.

Sono catturate dall’app in esecuzione in locale con l’account dimostrativo `demo@example.com` e i suoi dati fittizi, a 390×844 punti @3x per il telefono e 1440×900 @2x per il desktop. Il file indica tema e schermata (per esempio `dark-home.webp`, `light-previsioni.webp`, `desktop-andamento.webp`).

Quando l’interfaccia cambia in modo visibile, aggiorna le schermate interessate mantenendo lo stesso nome file, così il README non va modificato.
